# Contributing

Thank you for your interest in contributing to fastapi-with-postgis!

How to contribute

1. Fork the repository and create a branch for your change: `git checkout -b my-feature`
2. Make small, focused commits with clear messages.
3. Open a Pull Request against `main` describing your changes.

Reporting issues

- For bugs, use the bug report template.
- For feature requests, use the feature request template.

Development

- Tests: If you add or change functionality, add tests. This project uses pytest — run tests with:

  ```bash
  pytest
  ```

- Formatting & linting: Please follow the existing code style. We recommend using:

  - black for formatting: `black .`
  - ruff or flake8 for linting

- Type checking: Use mypy if you add new public APIs.

Commit message style

- Use conventional commits style where practical (e.g., `feat:`, `fix:`, `chore:`).

Pull request process

- Provide a clear description of the change and why it is needed.
- Include tests or steps to reproduce for bug fixes.
- Link related issues in the PR description.

Thank you for helping improve this project — contributions are welcome!
